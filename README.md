# RELIC : 잊혀진 영웅

2000년대 피처폰 감성의 **2D 쿼터뷰 실시간 액션 RPG**.
작게 만들고, 깊게 완성한다. 자동 사냥 없이 캐릭터 하나를 직접 움직이며 베고, 피하고, 파밍한다.

- 순수 HTML5 Canvas + JavaScript (빌드 도구·외부 라이브러리 없음)
- 캐릭터·몬스터는 디자인 시트(`assets/design/design-sheet.webp`)에서 잘라낸 스프라이트 + 코드 모션
- 타일·이펙트·NPC 도트와 효과음/배경음은 코드로 생성
- 세로형 9:16 모바일 화면 기준, PC 키보드도 지원

## 실행

`index.html`을 브라우저에서 열면 바로 실행됩니다. 로컬 서버로 띄우려면:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

GitHub Pages에 그대로 올려도 동작합니다. 진행 상황은 브라우저 `localStorage`에 자동 저장됩니다.

## 구현된 내용 (build 0.3)

**핵심 루프** — 루멘 마을(NPC 대화·의뢰) → 필드 탐험 → 던전 & 보스 → 파밍 & 강화 → 다음 지역 해금

- **직업 4종 + 2차 전직 8종**: 검투사(가디언/버서커) · 레인저(스나이퍼/트래퍼) · 원소술사(아크메이지/워록) · 암살자(어쌔신/닌자). Lv.30에 촌장에게서 전직
- **전투**: 3단 콤보(베기 100% → 올려베기 130% 띄움 → 강타 180% 다운), 콤보 증폭(×2 +5% … ×5 +30%), 회피 i-frame, 경직·넉백·히트스톱, 조준 보조
- **스탯/데미지 공식**: GDD 수치 그대로 — `(ATK × SkillRate) × ElementMod × [100 / (100 + DEF)]`
- **5속성 상성**: 화염 → 자연 → 번개 → 냉기 → 화염, 암흑 ↔ 암흑 (+25%)
- **상태이상**: 화상·중독·빙결(둔화)·기절·저주
- **5개 지역, 몬스터 20종 + 보스 5종**: 잊혀진 숲 / 폐허 도시 / 용암 광산 / 얼어붙은 성 / 마계의 문
  - 지역 기믹: 덩굴 장벽 + 열쇠, 바닥 압력 스위치, 낙석, 빙판 관성, 차원 전환 보스
  - 보스는 체력 구간별 페이즈 전환, 바닥 텔레그래프(빨간 경고) 패턴, 폭주
- **몬스터 AI**: 순찰 → 추적 → 공격(예비동작) → 다운 / 근접·돌진·원거리·비행 타입
- **장비**: 8부위, 5등급(일반·고급·희귀·영웅·전설), 랜덤 옵션, 속성 무기
- **대장간 안전 강화** +1~+10 (실패해도 하락·파괴 없음), 철 조각 / 강화석 / 고급 강화석
- **마을 루멘**: 걸어 다니며 NPC에게 직접 말을 거는 방식. 촌장·대장장이·연금술사·여관·용병 길드·음유시인
- **퀘스트**: 메인 퀘스트 10개(지역별 토벌 + 보스), 반복 길드 의뢰, 3지선다 대화로 열리는 숨겨진 의뢰
- **미니맵**(탐험한 영역만 표시), 몬스터 도감(약점 표시), 경험치 레벨 차이 보정, 사망 시 마을 부활/부활석
- **스토리**: 프롤로그 + 3가지 엔딩(봉인 / 공존 / 귀환)
- **성장**: 스킬 레벨 1~5 + 스킬 룬(A/B/C), 세트 장비 5종, 장비 도감 보너스
- **재화**: 골드 · 보석(플레이로만 획득) · 던전 코인 · 명예 메달
- **장비 소환**: 1회/10회, 10회 희귀 보장, 80회 전설 천장
- **펫 6종**: 수상한 상인에게서 데려오는 보조형 동료 (재생·물약·이속·줍기·드랍·골드)
- **채집 & 제작**: 던전의 약초·광석·버섯 → 연금술사 제작 (물약, 도시락 버프, 강화석, 부활석)
- **NPC 호감도**: 약초 선물로 호감도를 올리면 할인·선물·비밀 정보
- **숨겨진 던전 검은 광산**, **어려움/악몽 난이도**, **심연의 탑 50층**(층별 제한 조건 + 10층마다 수호자)
- **전직 궁극기 8종**: 2차 전직 시 세 번째 스킬 슬롯 개방 (방벽·격노·데드아이·덫·메테오·저주·처형·분신술)
- **광차 선로 기믹**: 용암 광산에서 레버로 광차를 보내 무너진 갱도를 뚫고 몬스터를 들이받는다
- **시즌 이벤트**: 실제 계절에 맞춘 축제 — 이벤트 재화, 일일 미션, 교환소, 한정 칭호, 마을 장식
- **착한 BM 원칙**: 뽑기·VIP·강제 광고 없음. 필드 파밍만으로 엔딩 가능

## 스프라이트 & 모션

디자인 시트는 캐릭터마다 포즈가 한 장이라, 스프라이트를 부위별로 잘라 코드로 움직인다 (`js/anim.js`).
인간형은 허리선에서 상체와 좌·우 다리를 나누고, 이동 거리에 맞춰 보폭 위상이 진행되어 발이 미끄러지지 않는다.

| 상태 | 모션 |
| --- | --- |
| 대기 | 숨쉬기 (스쿼시·스트레치) |
| 이동 | 좌·우 다리 교차 걸음 + 몸 오르내림 + 상체 흔들림 / 4족은 앞·뒷다리 질주 / 날개 좌우 분리 날갯짓 / 유령 꼬리 물결 / 벌레 몸통 굽이침 / 슬라임 말랑 |
| 공격 | 다리는 딛고 허리를 축으로 상체를 젖혔다가 스프링처럼 휘두름 + 잔상 (2타 올려치기, 3타 점프 내려찍기) |
| 스킬 | 돌진 늘어나기, 회전베기 360° 회전, 그림자이동 압축, 시전 동작 |
| 회피 | 몸 중심 360° 구르기 + 잔상 |
| 피격 / 기절 / 다운 / 사망 | 흰색 플래시 + 반동 / 흔들림 / 쓰러짐 / 기울며 사라짐 |

디자인 시트를 바꾸면 `python3 tools/extract_sprites.py`로 아틀라스를 다시 만든다 (좌표·크기는 스크립트 상단 표에서 조정).
