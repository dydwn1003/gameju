# 몬스터 키우기 (gameju)

몬스터 수집 · 강화 · 진화 · 자동전투 · 스테이지 방치형 웹게임 (모바일 세로 화면 기준)

## 실행
`index.html`을 브라우저로 열면 됩니다. (빌드 과정 없음, 진행 상황은 브라우저 localStorage에 저장)

## 화면 구성
- 위 2/3: 자동 전투 필드 (좌측 출석·퀘스트, 우측 방치보상·2배 부스트)
- 아래 1/3: 메뉴 (전투 / 몬스터 / 소환 / 모험 / 상점)

## 주요 시스템
- **메인 캐릭터**: 남자/여자 × 전사·도적·마법사·궁수 (성능은 비슷하고 스킬 스타일만 다름), 💎200으로 외형·직업 변경
- **파트너 몬스터**: 캐릭터 + 몬스터 최대 4마리가 팀
- **장비**: 캐릭터 4칸(무기·갑옷·투구·반지), 몬스터 2칸(목걸이·부적, 몬스터끼리 돌려 쓰기), +15 강화(성공률), 분해→강화석, 장비 소환
- **재화**: 골드 · 다이아 · 진화석 · 강화석
- **자동 전투 / 스테이지**: 팀이 자동으로 싸우며 스테이지를 올라감. 10스테이지마다 보스. 패배하면 최고 기록 스테이지를 반복 사냥.
- **속성 상성**: 불 › 풀 › 물 › 불, 빛 ⇄ 어둠 (1.5배)
- **육성**: 레벨업(골드) → 최대 레벨에서 진화석으로 진화(3단계) → 중복 조각으로 성급(★5)
- **수집**: 22종 오리지널 몬스터, N/R/SR/SSR/UR 등급, 도감
- **소환(뽑기)**: 1회 100다이아 / 10회 900다이아(SR 이상 확정) / 80회 천장(SSR 이상)
- **방치 보상**: 최고 스테이지 기준으로 실시간·오프라인 누적 (최대 12시간)
- **탐험**: 30분/2시간/8시간 파견 → 다이아·진화석·강화석·골드
- **출석**: 7일 주기 보상 (광고로 2배)
- **일일 퀘스트**: 7개 + 올클리어 보상
- **보스 레이드**: 요일별 거대 보스, 45초 동안 입힌 피해량만큼 보상, 처치 시 레벨업 (하루 3회 + 광고)
- **아레나**: 비슷한 전투력 상대 3명 중 선택, 점수·티어(브론즈~마스터) (하루 5회 + 광고)
- **사운드**: 합성 칩튠 BGM 4곡 + 효과음 17종 (설정에서 끄기 가능)
- **PWA**: 웹서버로 열면 홈 화면에 앱처럼 설치 가능, 오프라인 실행

| 소환 | 무료 1회 소환 | 3 |
| 탐험 | 30분 단축 | 10 |
| 상점 | 다이아 30 | 5 |
| 장비 소환 | 무료 1회 | 2 |

| 레이드 | 입장권 +1 | 2 |
| 아레나 | 입장권 +1 | 3 |

인앱 상품: 다이아 충전 4종, 스타터 패키지(1회), 광고 제거 패스(광고 없이 광고 보상 즉시 획득), 다이아 → 재화 교환

### 실제 광고/결제 연동
- `js/monetize.js`의 `showRewarded()` — Google H5 Games Ads(`adBreak`)가 있으면 실제 광고, 없으면 5초 테스트 광고.
  `index.html` 상단 주석을 해제하고 `ca-pub-...`를 넣으면 활성화.
- 앱 출시(Google Play) 시: Capacitor로 감싸서 AdMob 보상형 광고 / Play Billing으로 `showRewarded()`·`purchase()`만 교체.
- 현재 결제는 **테스트 결제**(실제 과금 없음).

## 아트/사운드 교체
`assets/` 폴더에 정해진 이름으로 이미지·사운드를 넣으면 자동 적용됩니다. → [docs/ART_GUIDE.md](docs/ART_GUIDE.md) (귀여운 도트 스타일 · 제미나이 프롬프트 포함)

## 한 파일 플레이 버전
`python3 tools/build_artifact.py` → `dist/play.html`

## 파일 구조
- `js/data.js` 몬스터·등급·스킬·상점·광고 제한 등 밸런스 데이터
- `js/art.js` 몬스터 SVG 그림 생성기
- `js/game.js` 상태 저장, 성장 공식, 뽑기, 전투 로직
- `js/battleview.js` 전투 화면 이펙트
- `js/ui.js` 탭 화면 / 모달
- `js/monetize.js` 광고·결제
- `js/assets.js` 이미지 에셋 자동 감지
- `js/hero.js` 메인 캐릭터 도트 스프라이트
- `js/gear.js` 장비 생성·착용·강화·분해
- `js/audio.js` 효과음/BGM
