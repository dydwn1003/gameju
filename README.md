# 몬스터 키우기 (gameju)

몬스터 수집 · 강화 · 진화 · 자동전투 · 스테이지 방치형 웹게임 (모바일 세로 화면 기준)

## 실행
`index.html`을 브라우저로 열면 됩니다. (빌드 과정 없음, 진행 상황은 브라우저 localStorage에 저장)

## 주요 시스템
- **자동 전투 / 스테이지**: 팀(최대 5마리)이 자동으로 싸우며 스테이지를 올라감. 10스테이지마다 보스. 패배하면 최고 기록 스테이지를 반복 사냥.
- **속성 상성**: 불 › 풀 › 물 › 불, 빛 ⇄ 어둠 (1.5배)
- **육성**: 레벨업(골드+먹이) → 최대 레벨에서 진화석으로 진화(3단계) → 중복 조각으로 성급(★5)
- **수집**: 22종 오리지널 몬스터, N/R/SR/SSR/UR 등급, 도감
- **소환(뽑기)**: 1회 100젬 / 10회 900젬(SR 이상 확정) / 80회 천장(SSR 이상)
- **방치 보상**: 최고 스테이지 기준으로 실시간·오프라인 누적 (최대 12시간)
- **탐험**: 30분/2시간/8시간 파견 → 젬·진화석·재화

## BM (수익화)
| 위치 | 광고 보상 | 일일 제한 |
|---|---|---|
| 방치 보상 | 2배 수령 | 10 |
| 부스트 | 30분간 전투속도·방치보상 2배 | 6 |
| 소환 | 무료 1회 소환 | 3 |
| 탐험 | 30분 단축 | 10 |
| 상점 | 젬 30 | 5 |

인앱 상품: 젬 충전 4종, 스타터 패키지(1회), 광고 제거 패스(광고 없이 광고 보상 즉시 획득), 젬 → 재화 교환

### 실제 광고/결제 연동
- `js/monetize.js`의 `showRewarded()` — Google H5 Games Ads(`adBreak`)가 있으면 실제 광고, 없으면 5초 테스트 광고.
  `index.html` 상단 주석을 해제하고 `ca-pub-...`를 넣으면 활성화.
- 앱 출시(Google Play) 시: Capacitor로 감싸서 AdMob 보상형 광고 / Play Billing으로 `showRewarded()`·`purchase()`만 교체.
- 현재 결제는 **테스트 결제**(실제 과금 없음).

## 파일 구조
- `js/data.js` 몬스터·등급·스킬·상점·광고 제한 등 밸런스 데이터
- `js/art.js` 몬스터 SVG 그림 생성기
- `js/game.js` 상태 저장, 성장 공식, 뽑기, 전투 로직
- `js/battleview.js` 전투 화면 이펙트
- `js/ui.js` 탭 화면 / 모달
- `js/monetize.js` 광고·결제
