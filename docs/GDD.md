## 4. 전투 공식 (COMBAT MATH)

| 스탯 | 영향 | 공식 |
| --- | --- | --- |
| STR | 근접 물리 공격 | 공격력 = STR × 2.0 + 무기공격력 + 보너스옵션 |
| DEX | 공격속도·원거리·명중 | 공격속도 = 기본치 × (1 + DEX × 0.002) |
| INT | 마법 공격·최대 MP | 마법공격력 = INT × 2.2 + 지팡이옵션 |
| VIT | 최대 HP·방어 | 방어력 = VIT × 1.5 + 방어구수치 |
| LUK | 치명타·레어 드랍 | 치명타율 = 5% + LUK × 0.05% |

**최종 피해** = (ATK × SkillRate) × ElementMod(1.25) × [100 / (100 + DEF)] — ✅ `js/entities.js` `hitMob()`

- Lv.1 검투사 HP 320 · STR 12 / Lv.2 필요 EXP 100 / 슬라임 HP ≈ 75 / 고블린 EXP 18 — ✅ (`js/data.js`)

## 5-1. 스킬 연계

- ✅ 기본 공격 적중 → MP 5% 회복 (공격과 스킬의 순환)
- ✅ 공격 적중 후 스킬로 후딜 캔슬 / 스킬 후반(55%)에 다른 스킬로 즉시 연결
- ✅ 스킬 종료 1.6초 안에 다른 스킬 → 연계 단계 +1 (최대 3): 단계당 피해 +20%, MP -15%
- ✅ 3타 마무리 직후 스킬 = 콤보 연계 (1단계 + 10%)

## 10. 엔티티 데이터 모델

```ts
interface PlayerEntity {
  id: string; job: 'GLADIATOR' | 'RANGER' | 'MAGE' | 'ASSASSIN';
  level: number; exp: number;
  baseStats: { str: number; dex: number; int: number; vit: number; luk: number };
  equipSlots: { weapon?: Item; armor?: Item; ring?: Item; /* ... */ };
  stateMachine: 'IDLE' | 'WALK' | 'ATTACK_1' | 'SKILL' | 'I_FRAME_DODGE';
}
interface MonsterEntity {
  id: string; name: string; hp: number; maxHp: number; def: number;
  element: 'FIRE' | 'ICE' | 'THUNDER' | 'NATURE' | 'DARK';
  aiState: 'PATROL' | 'CHASE' | 'ATTACK' | 'DOWNED';
  dropTable: Array<{ itemId: string; rate: number }>;
}
```

데이터 테이블은 모두 `js/data.js`에 모여 있어 밸런스 조정 시 코드 수정 없이 수치만 바꾸면 된다.
