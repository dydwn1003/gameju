# 도트 애니메이션 이미지 규격

지금 캐릭터·몬스터는 디자인 시트의 **포즈 한 장**을 통째로 움직여(통통 튀는 걸음, 내딛는 공격, 무기 궤적) 연출합니다.
진짜 걷는 다리, 칼을 휘두르는 팔처럼 자연스러운 동작은 **프레임 이미지**가 있어야 가능합니다.
이미지를 넣으면 코드 수정 없이 자동으로 프레임 애니메이션으로 바뀝니다.

## 한 캐릭터 = PNG 한 장

`assets/anim/TEMPLATE.png` (보기용 `TEMPLATE_x4.png`) 위에 그리면 됩니다.

| | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| **0줄: 아래(정면)** | 대기 | 걷기1 | 걷기2 | 걷기3 | 걷기4 | 공격1 (예비) | 공격2 (타격) | 공격3 (복귀) | 피격 |
| **1줄: 위(뒷모습)** | 〃 | | | | | | | | |
| **2줄: 옆(오른쪽)** | 〃 | | | | | | | | |

- 칸 크기: 기본 **32×48px** (다른 크기면 `python3 tools/make_anim_template.py 24 32`처럼 새 템플릿 생성)
- 배경: **투명** PNG
- 발끝: 칸 아래 빨간 선(아래에서 3px)에 맞추기, 몸 중심은 파란 점선
- 왼쪽은 오른쪽 그림을 좌우 반전해서 쓰므로 그리지 않아도 됩니다
- 걷기 4프레임은 "왼발 앞 → 모음 → 오른발 앞 → 모음" 순서, 한 칸 이동에 2프레임씩 재생됩니다
- 공격 3프레임은 공격 시간에 맞춰 늘어나 재생됩니다 (예비 → 타격 → 복귀)
- 몬스터도 같은 규격 (무기 없는 몬스터는 공격 칸에 몸통 박치기·물기 등)

## 등록

1. 이미지를 `assets/anim/<키>.png`로 저장 (키 = `GLADIATOR`, `RANGER`, `MAGE`, `ASSASSIN`, 전직 `GUARDIAN`…, 몬스터 `slime`, `goblin`… — `js/data.js` 참고)
2. `assets/anim/manifest.js`에 한 줄 추가

```js
R.ANIM_SHEETS.GLADIATOR = { src: 'assets/anim/GLADIATOR.png', fw: 32, fh: 48 };
```

칸 배치를 바꿨다면 `rows`, `idle`, `walk`, `attack`, `hurt`로 칸 번호를 지정할 수 있고,
3배 크기로 그렸다면 `scale: 3`을 주면 됩니다.

## 이미지를 줄 때 최소한 필요한 것

- 직업 4종 × (아래·위·옆 3방향 × 대기1 + 걷기4 + 공격3) = 캐릭터당 24프레임
- 전직 8종은 기본 직업 이미지를 써도 되고, 따로 주면 전직 후 그 이미지로 바뀝니다
- 몬스터는 옆모습 한 줄(대기·걷기·공격)만 있어도 동작합니다 (위·아래는 옆 줄로 대체)
