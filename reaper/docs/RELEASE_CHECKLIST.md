# 저승사자 키우기 — 출시 점검표

> 사용자가 **"출시 준비해줘" / "출시 준비 다 됐어"** 라고 하면 Claude 가 이 순서대로 진행하고, 사용자에게도 단계마다 알려 준다.
> 빌드(APK · AAB · TestFlight)는 사용자가 요청할 때만 돌린다. 이 문서의 4단계는 "출시 준비해줘"가 곧 요청이다.

---

## 0. 출시 전 확인 (사용자 쪽)
- [ ] 구글 비공개 테스트 **테스터 12명 · 14일** 채움
- [ ] 통신판매업 신고번호 · 신고기관 → Play Console 결제 프로필 "한국 개발자 추가 정보"에 입력
- [ ] 게임제작업 신고 확인 (구청)
- [ ] 구글 결제 프로필(비즈니스) 통장 인증 완료 · 애플 유료 앱 계약 **활성**
- [ ] AdMob 지급 정보(사업자 · 통장), 유럽 동의 메시지 게시
- [ ] 구글 OAuth "앱 게시"(브랜딩에 노션 주소 · `notion.site`) — 테스트 사용자 아닌 사람도 구글 로그인
- [ ] 카카오 비즈 앱 + 카카오계정(이메일) 동의항목 → KOE205 없이 로그인
- [ ] 애플 App ID 에 Sign in with Apple 체크, Supabase Apple Client IDs = `com.jeoseungsaja.idle`
- [ ] Supabase `server/schema.sql` 최신본 실행 (운영자 방명록 숨기기 `mod`)
- [ ] 운영자 등록(admins 표에 내 UID) — 공지 · 우편 · 문의 답변 · 신고 처리용

## 1. 코드 (Claude)
- [ ] `js/config.js` → `APP.admob.testing: false` (실제 광고)
- [ ] 광고 ID 확인
  - Android 앱 ID `ca-app-pub-7300932926935302~8958752839` (AndroidManifest)
  - Android 보상형 `ca-app-pub-7300932926935302/9313976058`
  - iOS 앱 ID `ca-app-pub-7300932926935302~6776451783` (Info.plist)
  - iOS 보상형 `ca-app-pub-7300932926935302/4346388700`
- [ ] `APP.version` 확인 (예 1.0.0) — 빌드 번호는 워크플로가 자동 증가
- [ ] Supabase 주소 · 공개 키, 로그인 버튼(구글 · 카카오 · 애플(iOS)) 확인. 네이버는 숨김 유지
- [ ] 테스트용 설정 · 디버그 코드 없음 (웹 테스트 결제 `testPay()` 는 앱에서는 안 쓰임 확인)
- [ ] 회귀 테스트 · 번역 누락 검사 통과 → 커밋 · 푸시

## 2. 출시용 빌드 (Claude)
- [ ] 안드로이드 **AAB** (reaper-android.yml) → Releases 링크 전달
- [ ] **TestFlight** (reaper-ios.yml) → App Store Connect 에 처리 완료 확인

## 3. 실제 광고 · 결제 점검 (사용자 + Claude)
**광고**
- [ ] AdMob → 설정 → **테스트 기기**에 내 폰 등록 (광고 ID 로 등록) → 실제 광고 ID 로도 내 폰엔 테스트 광고만 → 계정 정지 위험 없음
- [ ] 모든 광고 버튼: 2배 부적 · 옥 +10 · 영물 무료 소환 · 파견 단축 · 원귀 3배 · 복귀 2배 · 백귀야행
- [ ] ⚠️ 테스트 기기 등록 전엔 내 폰에서 **실제 광고를 누르지 않기**
- [ ] 광고 제거 구매 뒤 광고 없이 보상 즉시 받는지

**결제**
- [ ] 라이선스 테스트 계정(구글) · 샌드박스 계정(애플)으로 16개 중 대표 상품 결제 → 지급 확인
  - 옥 100 · 신입 차사 패키지(1회 한정) · 승진 응원(하루 1회) · 염라의 인장 · 광고 제거 · 특제 의자 1개
- [ ] 구매 복원 (설정 → 구매 복원): 광고 제거 · 신입 패키지 복원
- [ ] 같은 결제가 두 번 지급되지 않는지 (앱 껐다 켜기)
- [ ] (선택) 실제 카드로 ₩1,200 한 번 결제 → 지급 확인 → Play Console 주문 관리에서 **환불**

**그 밖**
- [ ] 로그인 3종 · 로그아웃 · 계정 삭제 · 클라우드 저장 이어 하기
- [ ] 알림 권한 · 홈 버튼 배경음 멈춤 · 언어 4종 전환 · 가격 통화

## 4. 제출
**구글**
- [ ] 프로덕션 → 국가/지역(한국 · 일본 · 미국 · 대만 · 홍콩 · 싱가포르 …) → 새 버전(출시용 AAB) → 출시 노트 → 검토 시작
- [ ] 콘텐츠 등급: 사용자 차단 · 신고 기능 **예**

**애플**
- [ ] 인앱 상품 16개(비소모성: starter_pack · remove_ads) — 가격 · 현지화 · 심사 스크린샷, 제출 준비 완료
- [ ] 버전 화면: 스크린샷(iPhone 6.9″ 1290×2796, iphone_1~5.jpg) · 설명 · 키워드 · 지원 URL · 출시용 빌드 선택 · 앱 내 구입 선택
- [ ] 앱 개인정보 보호(광고 ID = 추적에 사용됨) · 연령 등급 · 가격 및 사용 가능 국가
- [ ] 심사 메모: "게스트로 시작하면 로그인 없이 모든 기능 확인 가능. 계정 삭제: 설정 → 계정 삭제"
- [ ] 심사에 제출

## 5. 출시 직후
- [ ] AdMob → 앱마다 **스토어 추가**(구글 · 애플 연결) → 검토 후 "광고 게재 제한" 해제
- [ ] (선택) 개발자 웹사이트에 `app-ads.txt`
- [ ] 공지 · 우편으로 출시 기념 보상
- [ ] 첫 실제 결제 · 광고 수익 들어오는지, 1:1 문의 · 신고 확인
