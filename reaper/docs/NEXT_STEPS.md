마지막 작업: 2026-11-09 밤. 다음 대화를 시작하면 **1번부터** 이어서 하면 됩니다.

## 1. iOS TestFlight 업로드 마무리 ← 여기부터!
- **상태:** 안드로이드 서명 빌드는 성공했어요(Releases 에 `reaper-1.0.0-104` APK · AAB).
  iOS 는 **`ASC_KEY_P8_BASE64` 값이 .p8 키로 읽히지 않아서** 키 확인 단계에서 멈춰 있어요.
- **로그:** 풀어 본 첫 줄이 70글자예요. 키 파일 머리줄 `-----BEGIN PRIVATE KEY-----` 이 아니라는 뜻이에요.
- **할 일:**
  1. 받아 둔 `AuthKey_<키ID>.p8` 파일을 메모장(맥은 텍스트 편집기)으로 열어요.
  2. **전체 내용을 그대로** 복사해요. `-----BEGIN PRIVATE KEY-----` 부터 `-----END PRIVATE KEY-----` 까지, 4~6줄이에요.
  3. GitHub → gameju → Settings → Secrets → Actions → `ASC_KEY_P8_BASE64` → **Update** 에 붙여 넣어요.
     - 워크플로가 그대로 붙인 값도, base64 로 바꾼 값도 둘 다 받게 고쳐 두었어요.
  4. `ASC_KEY_ID` 가 그 `.p8` 파일 이름의 키 ID 와 같은지 확인해요.
     `ASC_ISSUER_ID` 는 App Store Connect 의 "발급자 ID" 예요.
  5. Claude 에게 "iOS 빌드 다시 돌려줘"라고 말하면 돼요. 화면의 Run workflow 버튼은 기본 브랜치에 워크플로가 없어서 안 보여요.
- **성공하면:** App Store Connect → TestFlight 에 10~30분 뒤 나타나요.

## 오늘 전체 플레이 점검에서 고친 것 (2026-11-09)
- **자리 비움 보상이 안 뜨던 문제:** 켜자마자 다른 곳에서 저장하면 비운 시간이 0이 됐어요. 이제 불러올 때 시간을 따로 기억해요.
- **튜토리얼 · 집무실 안내가 멈추던 문제:** 안내 도중에 앱을 껐다 켜면 다시 안 떴고, 그 뒤 단서 퀘스트와 집무실 안내까지 막혔어요. 이제 그 단계부터 이어서 떠요.
- **안내 상자가 창 버튼을 가리던 문제:** 복귀 보상 "받기"를 못 누를 수 있었어요. 이제 창이 열려 있는 동안 안내는 숨어요.
- **모든 창 오른쪽 위에 ✕ 닫기:** 긴 정보창도 바로 닫을 수 있어요.
- **공지 팝업 타이밍:** 집무실 · 꾸미기 · 메뉴 사용 중에 뜨지 않고, 마을 화면으로 돌아오면 떠요.
- **문구 정리:** 우편 · 순위 · 이웃 안내의 "claude.ai" 문구를 "로그인하면 …"으로 바꿨어요. 서버가 있으면 로그인 버튼도 보여요.
- **조사 오류:** "망각초**를** 심었어요", "연꽃차**를** 마셨다" 등을 고쳤어요.

**확인한 흐름 (오류 없음):**
- 캐릭터 만들기(빈 이름 · 1글자 · 욕설 막힘) → 스토리 → 튜토리얼 6단계 → 모든 HUD 버튼 · 탭 · 하위 탭
- 성장 → 승진 시험 → 집무실 안내 4단계(결재 · 파견 · 심판) → 꾸미기 상점 구매
- 꽃 심기 · 수확 → 주막 → 파견 시간 단축(옥) · 보상
- 영물 10회 소환 → 테스트 결제 · 광고 → 자리 비움 보상 → 설정(개인정보 · 처음부터 취소)
