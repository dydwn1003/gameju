## 1단계. 돈 받을 준비 (계약 · 세금 · 은행) — 가장 먼저, 며칠 걸려요
> 이게 **활성**이 아니면 인앱 상품이 앱에서 안 떠요.

1. App Store Connect 첫 화면 → **비즈니스** (예전 이름: 계약, 세금 및 금융 거래)
2. **유료 앱(Paid Apps)** 계약 → **보기 및 동의** → 동의
3. **은행 계좌 → 추가**
   - 국가: **대한민국** · 통화: **KRW**
   - 은행: 카카오뱅크 (물으면: 은행 코드 `090`, SWIFT `KAKOKR22`)
   - 예금주: **통장과 똑같이** (영문을 물으면 여권 영문 이름), 계좌번호
4. **세금 양식 → 미국 세금 양식** → **W-8BEN** (한국에 사는 개인)
   - 국적 · 거주 국가: 대한민국, 미국 납세자 번호(TIN): 없음
   - 외국 납세자 번호(Foreign TIN): 주민등록번호 또는 사업자등록번호를 넣으라고 하면 넣기
   - 조세 조약: **대한민국** 선택 (애플이 세율을 안내해 줘요)
   - 한국 세금 정보(사업자등록번호 등)를 따로 물으면 그대로 입력
5. **담당자 연락처**: 경영 · 재무 · 기술 · 법무 · 마케팅 모두 **나**로
6. 상태가 **활성(Active)** 이 될 때까지 기다리기 (보통 1~3일)
7. **EU 판매자(DSA) 상태** — 앱 정보나 비즈니스 화면에서 물어요
   - 유럽에도 출시하려면 **판매자(Trader)** 로 등록해야 해요 (유료 상품을 팔기 때문). 이때 주소 · 전화 · 이메일이 유럽 스토어에 공개돼요.
   - 공개가 싫으면 **비판매자**로 두고, 4단계에서 **EU 국가를 빼고** 출시하면 돼요.

## 6단계. 인앱 상품 16개 (왼쪽 **수익화 → 앱 내 구입**)
1단계가 **활성**이어야 상태가 넘어가요. 표는 `SETUP_GUIDE.md` **B-3** 과 같아요.

1. **+ (생성)**
   - 유형: `starter_pack` · `remove_ads` = **비소모성**, 나머지 14개 = **소모성**
   - 참조 이름: 표의 이름 / 제품 ID: 표의 ID (구글과 똑같이, 나중에 못 바꿔요)
2. 상품 화면에서
   - **사용 가능 여부**: 모든 국가 (또는 4단계와 같게)
   - **가격**: 기준 국가 **대한민국** → 표의 ₩ 에 가장 가까운 가격 (다른 나라는 자동)
   - **App Store 현지화**: 한국어 + (선택) 영어 · 일본어 · 중국어 — 이름 · 설명은 `STORE_LISTING.md` 의 **인앱 상품 이름 · 설명 번역**
   - **심사 정보 → 스크린샷**: `docs/store/iap_review.jpg` (게임 상점 화면, 16개 모두 같은 것 써도 돼요)
   - 심사 메모: `하단 탭 상점 → 패키지 / 집무실 → 소품 상점(특제 의자)`
3. 상태가 **제출 준비 완료**가 되면 OK → 16개 반복
4. **샌드박스 테스터**: **사용자 및 액세스 → Sandbox → 테스터 +** (애플 계정으로 쓴 적 없는 새 이메일) → 아이폰 **설정 → App Store → 샌드박스 계정** 로그인 → TestFlight 앱에서 결제 시험 (돈 안 나감)
