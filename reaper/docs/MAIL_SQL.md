# 저승사자 키우기 — SQL 로 우편(보상) 보내기

> Supabase → **SQL Editor** → 아래 한 줄을 붙여 넣고 **Run**.
> 처음 한 번은 최신 `server/schema.sql` 전체를 실행해 두어야 `send_mail` 이 생겨요.
> 우편은 **로그인한 사람만** 받아요 (게스트는 로그인하면 받음). 한 사람이 한 우편을 한 번만 받아요.

## 기본 모양

```sql
select send_mail('제목', '받는 사람', p_jade => 옥, p_tickets => 소환권, p_hours => 혼(시간치), p_days => 받을 기간(일), p_body => '내용');
```

| 받는 사람 | 누가 받나 |
|---|---|
| `'all'` | 모두: 지금 하는 사람 + 받을 기간 안에 새로 시작하는 사람 |
| `'old'` | 지금 하고 있는 사람만 (보낸 시점에 이미 시작한 사람) |
| `'new'` | 새로 시작하는 사람만 (보낸 뒤 받을 기간 안에 처음 시작한 사람) |
| `'online'` | 지금 접속 중인 사람만 (보내는 순간 게임을 켜 두고 있던 사람) |
| `'user'` | 특정 플레이어 (`p_nicks => array['닉네임', …]`) |

| 값 | 뜻 | 안 쓰면 |
|---|---|---|
| `p_jade` | 옥 | 0 |
| `p_tickets` | 영물 소환권 | 0 |
| `p_hours` | 몇 시간치 혼 (받는 사람의 현재 수입 기준) | 0 |
| `p_decor` | 꾸미기 소품 id (예: `'cc5'`) | 없음 |
| `p_days` | 받을 수 있는 기간(일) | 7 |
| `p_body` | 내용 | 없음 |

보상은 하나 이상 넣어야 해요. 없는 닉네임이나 잘못된 받는 사람이면 오류가 나고 우편은 안 보내져요.

## 상황별 바로 쓰기

### 출시 · 오픈
**오픈 기념 선물** (지금 + 2주 안에 오는 사람 모두)
```sql
select send_mail('🎉 정식 오픈 기념 선물', 'all', p_jade => 300, p_tickets => 3, p_days => 14, p_body => '저승사자 키우기에 오신 것을 환영해요!');
```

**사전 테스트 참여 감사** (출시 전부터 하던 사람만)
```sql
select send_mail('🙏 테스트 참여 감사 선물', 'old', p_jade => 500, p_tickets => 5, p_days => 14, p_body => '비공개 테스트에 함께해 주셔서 감사해요.');
```

### 신규 환영
**새로 시작한 차사 환영 선물** (보낸 뒤 30일 동안 새로 시작하는 사람)
```sql
select send_mail('👋 신규 차사 환영 선물', 'new', p_jade => 200, p_tickets => 3, p_days => 30);
```
> 30일이 지나면 다시 하나 보내 주세요 (기간을 길게: `p_days => 90`).

### 점검 · 오류
**정기 점검 보상** (점검 전부터 하던 사람)
```sql
select send_mail('🔧 점검 보상', 'old', p_jade => 100, p_hours => 2, p_days => 7, p_body => '점검 동안 기다려 주셔서 감사해요.');
```

**긴급 점검 · 서버 오류 사과** (조금 더 크게)
```sql
select send_mail('🙇 긴급 점검 사과 보상', 'old', p_jade => 200, p_hours => 4, p_days => 7, p_body => '불편을 드려 죄송해요.');
```

**버그 보상** (지금 하는 사람 + 일주일 안에 오는 사람 모두)
```sql
select send_mail('🐞 오류 보상', 'all', p_jade => 150, p_days => 7, p_body => '오류를 고쳤어요. 이용에 불편을 드려 죄송해요.');
```

### 이벤트
**주말 · 명절 선물**
```sql
select send_mail('🎑 추석 맞이 선물', 'all', p_jade => 200, p_hours => 3, p_days => 5);
```

**깜짝 선물** (지금 접속 중인 사람만, 하루 안에 받기)
```sql
select send_mail('✨ 깜짝 선물!', 'online', p_jade => 50, p_days => 1, p_body => '지금 접속해 계신 차사님께만 드려요.');
```

**접속 이벤트 (특정 시간대)**: 이벤트 시간에 `online` 으로 보내면 그때 켜 둔 사람만 받아요.
```sql
select send_mail('⏰ 저녁 8시 접속 선물', 'online', p_jade => 80, p_days => 1);
```

**이벤트 당첨자** (닉네임으로, 여러 명은 쉼표)
```sql
select send_mail('🏆 이벤트 당첨 선물', 'user', p_jade => 500, p_tickets => 5, p_nicks => array['갓주', '차사왕']);
```

**꾸미기 소품 선물** (소품 id 는 게임 상점의 소품, 예: 특제 판관의 붉은 칠 교의 = `cc5`)
```sql
select send_mail('🪑 특별 소품 선물', 'all', p_decor => 'cc5', p_days => 14);
```

### 고객 응대
**1:1 문의 보상 · 결제 오류 보상** (그 사람에게만)
```sql
select send_mail('📮 문의 답변 보상', 'user', p_jade => 100, p_nicks => array['닉네임']);
```

**결제했는데 못 받은 경우** (산 상품만큼 옥으로 보상, 예: 옥 550개)
```sql
select send_mail('💎 결제 상품 지급', 'user', p_jade => 550, p_days => 30, p_body => '확인이 늦어 죄송해요.', p_nicks => array['닉네임']);
```

## 확인 · 지우기

**보낸 우편 목록** (한국 시간)
```sql
select * from mail_list;
```

**우편 지우기** (목록의 `path` 를 넣기, 이미 받은 사람의 보상은 그대로)
```sql
delete from public.docs where path = 'mail/m1794311233865';
```

**닉네임이 맞는지 먼저 확인**
```sql
select doc_id, data ->> 'nick' as nick from public.docs where col = 'rank' and data ->> 'nick' like '%갓주%';
```

## 참고
- "지금 / 새로 시작"은 **게임을 처음 시작한 날** 기준이에요. 다른 폰에서 같은 계정으로 로그인해도 처음 시작한 날이 따라가요.
- "접속 중"은 보낸 순간 게임이 켜져 있던 사람이에요 (2분 넘게 나갔다 오면 새 접속). 우편함 **N** 표시는 5분 안에 떠요.
- 우편함에는 최근 60통까지 보여요. 오래된 우편은 지워 두면 좋아요.
- 혼(시간치)은 받는 사람의 지금 수입 기준이라, 높은 계급일수록 많이 받아요.
